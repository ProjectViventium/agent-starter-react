# Provider logo files

`openai.svg`, `xai.svg`, `elevenlabs.svg`, `assemblyai.svg` are copied unchanged from the npm package
`@lobehub/icons-static-svg` version 1.102.0 (MIT licence). The marks belong to their owners and are used only to name the provider.
No logo is shipped for Cartesia or for the two on-device options (Whisper, Chatterbox); the picker draws a neutral tile for those.
